# RoboFriends

A small React + Redux app that loads a list of users and shows each one as a robot card you can search by name.

Built with React 19, Redux Toolkit, Vite and Tachyons. Tested with Vitest and React Testing Library.

## Run it

Requires Node.js 22.12 or newer.

```bash
npm install
npm run dev
```

| Script | What it does |
| --- | --- |
| `npm run dev` | Start the dev server |
| `npm run build` | Build for production into `dist/` |
| `npm run preview` | Serve the production build |
| `npm test` | Run tests in watch mode (`npm run test:run` runs once) |
| `npm run lint` | Lint with ESLint |
